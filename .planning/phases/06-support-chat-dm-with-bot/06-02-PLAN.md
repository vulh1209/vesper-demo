  <files>

  </files>
  <action>
1. Create `src/bot/events/app-home-opened.ts`:
   - Import app from '../app.js'
   - Import buildWelcomeBlocks from '../views/index.js'

   - Create in-memory Set for tracking welcomed users:
     ```typescript
     const welcomedUsers = new Set<string>();
     ```
     Note: In-memory is sufficient - resets on bot restart, which is acceptable behavior

   - Register `app.event('app_home_opened', async ({ event, client, say, logger }) => { ... })`

   - Get userId: `const userId = event.user`

   - Guard 1: If `welcomedUsers.has(userId)`, return early (already welcomed this session)

   - Try/catch block:
     - Call `client.conversations.history({ channel: event.channel, limit: 1 })`
     - If result.messages has length > 0: user has prior history
       - Add to welcomedUsers and return (no welcome needed)
     - Otherwise (truly first interaction):
       - Add to welcomedUsers
       - Send welcome: `await say({ channel: event.channel, blocks: buildWelcomeBlocks() })`
       - Log: `logger.info(\`Welcomed new user: \${userId}\`)`

   - Catch block: log error with logger.error, don't crash

2. Update `src/bot/index.ts`:
   - Add import `./events/app-home-opened.js` for side effects (after dm-message import)
  </action>
  <verify>
    - Run `npm run build` - compiles without errors
    - Run `npm run test` - existing tests pass
    - Check that app-home-opened.ts uses conversations.history with limit: 1
    - Check that welcomedUsers Set is used to prevent duplicate welcomes
  </verify>
  <done>
    - app_home_opened handler registered
    - First-time users receive welcome message when opening bot DM
    - Returning users (with message history) don't see welcome
    - Users welcomed this session don't see repeated welcomes
  </done>
