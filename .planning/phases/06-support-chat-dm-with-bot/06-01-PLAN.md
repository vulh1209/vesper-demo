1. Create `src/bot/views/welcome.ts`:
   - Export `buildWelcomeBlocks()` returning `KnownBlock[]`
   - Header: "Welcome to Vesper!" (plain_text)
   - Section: "I help you track asset versions. Just tell me what you're looking for!"
   - Divider
   - Section with examples:
     - "ho ly" - Find the latest version of Ho Ly
     - "boss theme" - Search for Boss Theme assets
     - "Just type any asset name!"
   - Context tip: "Tip: You can also @mention me in channels or use /vesper command."
   - Use bullet character \u2022 for list items (not emoji)

2. Update `src/bot/views/index.ts`:
   - Add export for `buildWelcomeBlocks` from `./welcome.js`

3. Create `src/bot/events/dm-message.ts`:
   - Import app from '../app.js'
   - Import findAssetByName, getAssetDetail, searchAssets from services/query
   - Import buildAssetResultBlocks, buildSearchResultsBlocks, buildWelcomeBlocks from views
   - Import GenericMessageEvent from '@slack/types'

   - Register `app.message()` handler with async callback
   - Type assertion: `const msg = message as GenericMessageEvent`

   - Guard 1: `if (msg.channel_type !== 'im') return` - only handle DMs
   - Guard 2: `if (msg.bot_id) return` - prevent self-response loops
   - Guard 3: `if (msg.subtype !== undefined) return` - ignore edits/deletes

   - Extract text: `const text = msg.text?.trim()`
   - If empty text: `await say({ blocks: buildWelcomeBlocks() })` and return

   - Try/catch block with same logic as app-mention:
     - Try exact match with findAssetByName(text)
     - If found, get full details with getAssetDetail and respond with buildAssetResultBlocks
     - Otherwise, search with searchAssets({ query: text, limit: 5 })
     - If no results: plain text "I couldn't find any assets matching..."
     - Otherwise: respond with buildSearchResultsBlocks

   - Catch block: log error, respond with "Sorry, something went wrong"

   - KEY DIFFERENCE from app-mention: NO thread_ts (DMs are direct, not threaded)

4. Update `src/bot/index.ts`:
   - Add import `./events/dm-message.js` for side effects (after app-mention import)
  </action>
