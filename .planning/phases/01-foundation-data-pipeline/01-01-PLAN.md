<task type="auto">
  <name>Task 1: Initialize TypeScript project with dependencies</name>
  <files>
    package.json
    tsconfig.json
    .env.example
    src/index.ts
  </files>
  <action>
1. Initialize npm project: `npm init -y`

2. Install production dependencies:
```bash
npm install @slack/bolt drizzle-orm postgres bullmq ioredis zod date-fns fuse.js dotenv
```

3. Install dev dependencies:
```bash
npm install -D typescript drizzle-kit @types/node tsx
```

4. Create `tsconfig.json` with strict mode:
```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true,
    "outDir": "dist",
    "rootDir": "src",
    "declaration": true,
    "resolveJsonModule": true
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist"]
}
```

5. Add scripts to `package.json`:
```json
{
  "scripts": {
    "dev": "tsx watch src/index.ts",
    "build": "tsc",
    "start": "node dist/index.js",
    "db:generate": "drizzle-kit generate",
    "db:migrate": "drizzle-kit migrate",
    "db:push": "drizzle-kit push",
    "db:studio": "drizzle-kit studio"
  }
}
```

6. Create `.env.example` with all required environment variables:
```
# Database
DATABASE_URL=postgres://vesper:vesper@localhost:5432/vesper

# Redis (for BullMQ)
REDIS_URL=redis://localhost:6379

# Slack
SLACK_BOT_TOKEN=xoxb-your-bot-token
SLACK_SIGNING_SECRET=your-signing-secret
SLACK_APP_TOKEN=xapp-your-app-token

# Workspace
SLACK_WORKSPACE_URL=https://your-workspace.slack.com
```

7. Create `src/index.ts` with a simple startup message:
```typescript
import 'dotenv/config';

console.log('Vesper starting...');
console.log('Database URL configured:', !!process.env.DATABASE_URL);
console.log('Redis URL configured:', !!process.env.REDIS_URL);
console.log('Slack token configured:', !!process.env.SLACK_BOT_TOKEN);
```
  </action>
  <verify>
    - `npm run build` completes without errors
    - `node dist/index.js` outputs startup message
    - All dependencies listed in package.json
  </verify>

    TypeScript project compiles, dependencies installed, environment template created
  </done>

<task type="auto">
  <name>Task 2: Set up Docker Compose for PostgreSQL and Redis</name>
  <files>
    docker-compose.yml
    drizzle.config.ts
  </files>
  <action>
1. Create `docker-compose.yml`:
```yaml
version: '3.8'

services:
  postgres:
    image: postgres:16-alpine
    container_name: vesper-postgres
    environment:
      POSTGRES_USER: vesper
      POSTGRES_PASSWORD: vesper
      POSTGRES_DB: vesper
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U vesper"]
      interval: 5s
      timeout: 5s
      retries: 5

  redis:
    image: redis:7-alpine
    container_name: vesper-redis
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 5s
      timeout: 5s
      retries: 5

volumes:
  postgres_data:
  redis_data:
```

2. Create `drizzle.config.ts`:
```typescript
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  schema: './src/db/schema.ts',
  out: './src/db/migrations',
  dialect: 'postgresql',
  dbCredentials: {
    url: process.env.DATABASE_URL!,
  },
  verbose: true,
  strict: true,
});
```

3. Create `.env` file (copy from .env.example with local defaults):
```
DATABASE_URL=postgres://vesper:vesper@localhost:5432/vesper
REDIS_URL=redis://localhost:6379
SLACK_BOT_TOKEN=
SLACK_SIGNING_SECRET=
SLACK_APP_TOKEN=
SLACK_WORKSPACE_URL=
```

4. Add `.env` to `.gitignore` if not already there
  </action>
  <verify>
    - `docker-compose up -d` starts both services
    - `docker-compose ps` shows both containers healthy
    - `docker-compose exec postgres psql -U vesper -c '\l'` lists databases
    - `docker-compose exec redis redis-cli ping` returns PONG
  </verify>

    PostgreSQL and Redis running locally via Docker Compose, Drizzle configured
  </done>
