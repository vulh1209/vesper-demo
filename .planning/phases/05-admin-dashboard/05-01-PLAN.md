Create src/api/routes/admin/jobs.ts:

Import from existing modules:
```typescript
import { Hono } from 'hono';
import { scrapeQueue } from '../../jobs/queue.js';
import { runScrapeNow, getSchedulerStatus } from '../../jobs/daily-scrape.js';
```

Implement endpoints:

GET /status - Return queue health:
```typescript
const counts = await scrapeQueue.getJobCounts('wait', 'active', 'completed', 'failed', 'delayed');
const scheduler = await getSchedulerStatus();
const isPaused = await scrapeQueue.isPaused();
return c.json({ ok: true, data: { counts, scheduler, isPaused } });
```

GET /recent - Return last 10 completed and last 10 failed jobs:
```typescript
const completed = await scrapeQueue.getJobs(['completed'], 0, 10, true);
const failed = await scrapeQueue.getJobs(['failed'], 0, 10, true);
// Map to { id, name, finishedOn, failedReason, data }
```

POST /trigger - Trigger immediate scrape:
```typescript
const body = await c.req.json().catch(() => ({}));
const channelIds = body.channelIds; // optional array
const jobId = await runScrapeNow(channelIds);
return c.json({ ok: true, data: { jobId } });
```

POST /pause - Pause queue (await scrapeQueue.pause())
POST /resume - Resume queue (await scrapeQueue.resume())
