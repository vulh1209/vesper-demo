<task type="auto">
  <name>Task 2: Create LLM provider configuration module</name>
  <files>src/config/llm.ts</files>
  <action>
Create `src/config/llm.ts` with:

1. **Type definitions:**
   - `LLMProvider` type: 'openai' | 'gemini'
   - `LLMConfig` interface with provider, model, modelId fields

2. **getLLMConfig() function:**
   - Check `LLM_PROVIDER` env var for explicit selection
   - If not set, check `GOOGLE_GENERATIVE_AI_API_KEY` presence (prefer Gemini if configured)
   - Fall back to OpenAI if only `OPENAI_API_KEY` is set
   - Use `gemini-2.0-flash` for Gemini (cheaper than 2.5)
   - Use `gpt-4o-mini` for OpenAI

3. **getModelWithFallback() function:**
   - If both providers configured: use `createFallback` from ai-fallback
   - Primary is Gemini (cheaper), fallback is OpenAI
   - Configure `modelResetInterval: 5 * 60 * 1000` (5 minutes)
   - Add `onError` callback for logging
   - If only one provider: return that model directly
   - If no provider: throw clear error message

4. **getProviderStatus() function:**
   - Return object with: `primary`, `fallback`, `hasFallback`
   - Used for health checks and status reporting

5. **hasFallbackAvailable() function:**
   - Simple boolean check if both API keys are set

Import patterns from research:
- `import { google } from '@ai-sdk/google';`
- `import { openai } from '@ai-sdk/openai';`
- `import { createFallback } from 'ai-fallback';`

Export all functions and types for use by intent.ts.
  </action>
  <verify>
Run `npx tsx -e "import { getLLMConfig, getProviderStatus } from './src/config/llm'; console.log(getProviderStatus());"` - should output provider status object
Run `npm run build` - TypeScript compiles without errors
  </verify>
  <done>
src/config/llm.ts exists with all four functions exported and TypeScript compiles successfully
  </done>
</task>
